# PolicyPulse

PolicyPulse is an AI-powered government policy retrieval and question-answering system built using Retrieval-Augmented Generation (RAG). The project enables users to search and understand government policies through natural language queries by leveraging semantic search and vector embeddings.

### Dataset

* Trained on approximately **3,500 government policy documents**.
* **Note:** The dataset is sourced from external government resources and is **not owned by the project contributors**.

### Tech Stack

* Python
* Data Cleaning & Preprocessing
* Text Embeddings
* FAISS (Facebook AI Similarity Search)
* Retrieval-Augmented Generation (RAG)

### Features

* Semantic search over government policy documents
* Fast document retrieval using FAISS vector indexing
* Natural language question answering
* Efficient preprocessing and embedding pipeline
